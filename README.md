Customer Behaviour Analysis

Project Overview

This data analytics project analyzes customer shopping behaviour to understand purchasing patterns, customer preferences, and spending trends.

Objectives

- Analyze customer purchasing patterns.
- Understand customer preferences across product categories.
- Explore customer spending and review ratings.
- Create interactive dashboards to communicate insights.

Tools & Technologies

- Python: Data cleaning and analysis using Pandas.
- SQL (PostgreSQL): Querying and analyzing customer data.
- Power BI: Creating interactive dashboards and visualizations.
- Jupyter Notebook: Writing and executing Python code.

Dataset

The project uses customer shopping behaviour data containing information such as age, gender, product category, purchase amount, location, review rating, subscription status, and payment method.

Project Workflow

1. Load and explore the dataset using Python.
2. Clean and prepare the data.
3. Analyze customer data using SQL.
4. Build interactive dashboards in Power BI.
5. Present findings through visualizations.

Files in This Repository

- "Project.ipynb" — Python analysis notebook.
- "customer_shopping_behavior.csv" — Customer dataset.
- "project1.pbix" — Power BI dashboard.
- "README.md" — Project documentation.

Key Learning Outcomes

- Data cleaning and exploratory data analysis.
- SQL queries and data aggregation.
- Power BI dashboard development.
- Data storytelling and visualization.
